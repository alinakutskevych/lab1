4. Semantic Web (Семантичний Веб)

← Повернутися на головну

А) Короткий опис та теорія

Semantic Web — концепція розвитку Інтернету (Web 3.0), мета якої зробити дані зрозумілими для автоматичної комп'ютерної обробки.

Б) Характеристики

  • Алгоритми: Графи знань, SPARQL-запити, онтологічний аналіз.
  • ПЗ: Protege, Apache Jena, GraphDB.
  • Сфери застосування: Пошукові системи нового покоління, відкриті дані.
